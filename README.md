# Primo Restaurant Dynamic Web Application
A dynamic, full-featured restaurant management and online food ordering system developed using PHP and modern frontend technologies.
## 🚀 Key Features
* **Dynamic Menu & Shopping Cart:** Fully functional cart system with live items updates (`cart.php`, `add_to_cart.php`).
* **Multi-Level Authentication:** Secure roles with multi-dashboard systems for customers, Administrators (`admin/`), and Global System Managers (`super_admin/`).
* **Complete Order Processing:** Automated order placement, checkout sequence, and transaction success logging (`checkout.php`, `process_order.php`).
* **Relational Database Design:** Efficient SQL structure with robust core data connectivity configurations (`db_connect.php`).
## 🛠️ Technologies Used
* Backend: PHP
* Frontend: HTML5 / CSS3 / JavaScript (DOM Architecture)
* Database: MySQL / SQL database connections
